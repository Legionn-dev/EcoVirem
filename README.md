Cieľ projektu

Hlavným cieľom projektu je vytvoriť mobilnú Android aplikáciu EcoTracker, ktorá slúži ako osobný "eko asistent". Aplikácia motivuje používateľov k udržateľnejšiemu životnému štýlu tým, že im umožňuje sledovať a znižovať ich uhlíkovú stopu. Využíva moderné technológie ako automatické rozpoznávanie textu z naskenovaných cestovných lístkov (Google ML Kit OCR) a gamifikáciu (30-dňové eko výzvy, body, odznaky). Cieľom je pomôcť používateľom budovať dlhodobé ekologické návyky a prehľadne vizualizovať ich pozitívny dopad na životné prostredie.
